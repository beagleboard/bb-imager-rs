= BeagleBoard Imaging Utility docs

Documentation for BeagleBoard Imaging Utility.

== How to build docs

The docs are built with the `ghcr.io/beagleboard/antora-docker` container image, using Podman
if it is installed and Docker otherwise:

[source,shell]
----
make docs          # build into build/site
make docs-serve    # build, then serve at http://localhost:8000
----

To force Docker, pass `CONTAINER=docker`.

Inside a git worktree, Antora cannot read the `.git` file, so the docs are copied (symlinks
dereferenced) to `target/docs` and built there. The site is then at `target/docs/build/site`.
