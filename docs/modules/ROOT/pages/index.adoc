= BeagleBoard Imaging Utility

The *BeagleBoard Imaging Utility* (bb-imager) is the official BeagleBoard.org tool for getting an
operating system onto your board. Pick your board, pick an image, pick your SD card. It downloads,
customizes, and writes the image for you. It runs on Linux, Windows, and macOS.

== About

bb-imager works for new users and experienced developers alike. It handles device detection and
image downloads, and guards against writing to the wrong disk.

Beyond writing images, it can pre-configure supported operating systems before first boot: user
account, hostname, Wi-Fi, timezone, keyboard layout, and SSH key. A board can then come up
ready to use without a monitor or keyboard.

It is written in Rust and plays a similar role to other popular imaging tools, but is tailored to
BeagleBoard hardware and the operating systems BeagleBoard.org recommends.
